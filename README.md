 # Printer PDV

  Programa para Windows que conecta o seu sistema Intrasis às impressoras do caixa.
  Com ele você imprime cupons, NFC-e, recibos e documentos A4 direto do sistema,
  em impressoras USB, de rede ou instaladas no Windows.

  ## Download

  Baixe sempre a versão mais recente:
  👉 https://github.com/eduardokum/printer-pdv-releases/releases/latest

  Execute o arquivo **PrinterPDV-Setup** e siga as instruções na tela.
  Depois de instalado, o Printer PDV abre junto com o Windows, fica ao lado do relógio
  e se atualiza sozinho.

  Requer Windows 10 ou 11 (64 bits).
